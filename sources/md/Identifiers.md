## Draft Metadata Scheme
| Term                      | Definition                                                                                                               | Remarks                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| abbreviation              | Acronym or Abbreviation commonly used to reference the identifier                                                        |                                                                                                                                                                                |
| assigningAuthorityName    | Full name of the assigning authority responsible for generating and registered identifiers                               |                                                                                                                                                                                |
| format                    | Regular expression or xsd:datatype                                                                                       |                                                                                                                                                                                |
| identificationScheme      | Reference to the system for minting identifiers for things that specifies constraints on the structure of the identifier | See FIBO-FND-ARR-ID                                                                                                                                                            |
| identifierScope           | Boundaries for which the identifier can be applied to a particular resource                                              | Catalog Numbers are locally scoped since they are unique within the context of a single collection of institution. GUIDs are globally scoped since they are universally unique |
| registeredInstitutionCode | dwc:institutionCode of the organization the identifier is registered to                                                  |                                                                                                                                                                                |
| resourceType              | The type of information element for which the identifier can be allocated                                                | irg:IRIResourceType                                                                                                                                                            |
| serviceEndpoint           | A service endpoint where the new identifiers can be generated                                                            |                                                                                                                                                                                |
| title                     | Formal title of the identifier                                                                                           | Full unabbreviates name                                                                                                                                                        |
